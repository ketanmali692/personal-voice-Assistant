# 🎙️ Personal Voice Assistant

A Windows-based personal voice assistant built with Python. It can open/close apps, search the web, send WhatsApp messages, take pictures, set reminders, send emails, and answer questions using Claude AI.

---

## ✨ Features

- 🎤 **Voice Commands** — Natural language in English/Hinglish
- 🤖 **AI Fallback** — Unknown questions answered by Claude AI (optional)
- 🔔 **Wake Word** — Say "Hey Assistant" to activate
- 🖥️ **GUI** — Tkinter window with live conversation
- 📝 **Logging** — All conversations saved to `logs/assistant.log`
- ⚙️ **Config File** — Customize via `config.json`
- 🛡️ **Safe Mode** — Confirmation before shutdown/restart/close-all
- 🌦️ **Weather** — Live weather for any city
- 📚 **Wikipedia** — Quick summaries
- 📧 **Email** — Send emails via Gmail
- 💬 **WhatsApp** — Voice-controlled WhatsApp messaging
- ⏰ **Reminders & Alarms** — Set timers and alarms
- 📸 **Camera & Screenshots**
- ☕ **Java File Creator** — Auto-generate `.java` files
